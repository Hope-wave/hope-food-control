Controle de estoque de alimentos

1

Cadastro de Alimento

Registre entradas no estoque e gere o ID de etiquetagem.

Sem o dia na embalagem? Use o último dia do mês indicado. Ex.: validade 03/2027 → 31/03/2027.

2

Registrar Saída

Informe o ID da etiqueta para retirar 1 unidade.

O ID fica na etiqueta colada no alimento. Pode digitar com letra maiúscula ou minúscula.

Cesta básica

Montagem de Cesta Básica

Os 7 itens da base são obrigatórios; adicionais entram quando houver estoque. A lista prioriza os alimentos com validade mais próxima.

  1. Calcular montagem para gerar a lista de etiquetas.
  2. Separe cada item pelo ID da etiqueta. Não achou? Clique em Não encontrei.
  3. Registrar saída para dar baixa no estoque.
